# Elkenno Life Sciences

Official website for **Elkenno Life Sciences Pvt. Ltd.** — Manufacturer of premium organic fertilizers, liquid foliar sprays, and granular soil amendments engineered for sustainable agriculture in India.

## 🌿 Features

- **Home Page**: Interactive hero banner, company highlights, product showcase, certifications, testimonials, and FAQs.
- **About Us**: Mission, vision, core values, leadership, and sustainability commitments.
- **Products Catalog**: Detailed product specifications, benefits, application methods, and composition details.
- **Media & News**: Product brochures, agricultural resources, downloadable PDF guides, and latest announcements.
- **Contact & Inquiries**: Interactive contact form, Google Maps integration, customer support, and dealer inquiry details.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.
- **SEO & Social Meta**: Open Graph, Twitter Cards, structured schema data, and dynamic page metadata via React Helmet Async.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) with [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **UI Components & Icons**: [Radix UI](https://www.radix-ui.com/), [Lucide React](https://lucide.dev/), [Sonner](https://sonner.emilkowal.ski/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Animations & Carousel**: [Embla Carousel](https://www.embla-carousel.com/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/) (included with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/dwebworks24/elkennolifesciences-89b16aba.git
   cd elkennolifesciences-89b16aba
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the local development server:
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the application.
